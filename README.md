# 開工吧！社畜人生！

把派工給 AI coding agent 變成一座像素小島的城市經營遊戲：每棟建築是一個專案，每個員工是一個在自己工作區寫程式的 agent。

A pixel-art island city-builder where every building is a project and every employee is a coding agent.

## 下載 / Download

到 [Releases](https://github.com/tackcrypto1031/kaigong-agent/releases/latest) 下載最新版本：

| 系統 / System | 檔案 / File |
|---|---|
| Windows（安裝版，會自動更新） | `agent-factory-<版本>-setup.exe` |
| Windows（免安裝） | `agent-factory-<版本>-win-x64.zip` |
| Mac（Apple Silicon） | `agent-factory-<版本>-mac-arm64.dmg` |
| Mac（Intel） | `agent-factory-<版本>-mac-x64.dmg` |

- Windows 第一次開啟時 SmartScreen 可能會跳警告，按「其他資訊 → 仍要執行」即可。
- Mac 版沒有 Apple 簽章，第一次開啟要到「系統設定 → 隱私權與安全性」按「強制打開」。
- 安裝版 Windows 之後會在 App 裡自動收到更新；免安裝版和 Mac 版會提示有新版本並連到下載頁。

This repository only hosts releases.
